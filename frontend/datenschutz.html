3. Datenerfassung auf dieser Website

Server-Logfiles
Der Hosting-Provider dieser Website erhebt und speichert automatisch Informationen in sogenannten Server-Logfiles, die Ihr Browser automatisch übermittelt. Dies sind:

  • Browsertyp und Browserversion
  • verwendetes Betriebssystem
  • Referrer URL
  • Hostname des zugreifenden Rechners
  • Uhrzeit der Serveranfrage
  • IP-Adresse

Diese Daten werden nicht mit anderen Datenquellen zusammengeführt. Die Erfassung dieser Daten erfolgt auf Grundlage von Art. 6 Abs. 1 lit. f DSGVO. Der Websitebetreiber hat ein berechtigtes Interesse an der technisch fehlerfreien Darstellung und Optimierung seiner Website – hierzu müssen die Server-Logfiles erfasst werden.

Geolokalisierung (Standortermittlung)
Diese Website bietet die Möglichkeit, Ihren aktuellen Standort zu verwenden, um Wetterdaten für Ihre Position abzurufen. Die Standortermittlung erfolgt ausschließlich in Ihrem Browser und wird nur mit Ihrer ausdrücklichen Zustimmung durchgeführt. Die Standortdaten werden nicht auf unseren Servern gespeichert, sondern lediglich zur einmaligen Abfrage der Wetterdaten an die Open-Meteo API übermittelt.

Ortssuche
Bei der Nutzung der Ortssuche wird Ihre Suchanfrage an den Dienst Nominatim (OpenStreetMap) übermittelt, um die geografischen Koordinaten zu ermitteln. Dabei gelten die Datenschutzbestimmungen von OpenStreetMap.

4. Externe Dienste

Open-Meteo API
Diese Website nutzt die Open-Meteo API zur Abfrage von Wetterdaten. Bei der Abfrage werden die geografischen Koordinaten (Breiten- und Längengrad) an die Open-Meteo API übermittelt. Es werden keine personenbezogenen Daten wie IP-Adressen dauerhaft gespeichert. Weitere Informationen finden Sie in der Datenschutzerklärung von Open-Meteo.

Nominatim (OpenStreetMap)
Für die Geokodierung (Umwandlung von Ortsnamen in Koordinaten) wird der Dienst Nominatim von OpenStreetMap genutzt. Dabei wird Ihre Suchanfrage an die Server von OpenStreetMap übermittelt. Weitere Informationen finden Sie in der Datenschutzerklärung von OpenStreetMap.

Chart.js
Zur Darstellung von Diagrammen wird die Bibliothek Chart.js verwendet, die über ein CDN (Content Delivery Network) eingebunden wird. Dabei kann die IP-Adresse des aufrufenden Geräts an den CDN-Anbieter übermittelt werden.

Leaflet
Für die Kartendarstellung wird die Bibliothek Leaflet verwendet, die über ein CDN eingebunden wird. Dabei kann die IP-Adresse des aufrufenden Geräts an den CDN-Anbieter übermittelt werden.
